Tadabut · Server-side

208 users from DummyJSON, loaded one page at a time. Paging, sorting and search each ask DummyJSON again. It answers saves, adds and deletes, but doesn't keep them: the next load shows the old rows again.

Tick users on different pages: the age total counts them all (totalRows: 'selected'). The gender filter uses DummyJSON's /users/filter, which can't search at the same time, so the search box is ignored while it's set.
